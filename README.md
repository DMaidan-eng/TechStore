No necesita instalación ni dependencias.

1. Descargar o clonar el repositorio.
2. Abrir `index.html` en el navegador.
3. Opcionalmente, usar la extensión Live Server de VS Code.

## Estructura

TechStore/
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
- index.html: estructura de la página y formulario de alta.
- css/style.css: estilos y diseño visual.
- js/main.js: catálogo, filtros, carrito y manipulación del DOM.
Funcionalidades
- Catálogo generado dinámicamente desde un array de objetos.
- Búsqueda de productos por nombre en tiempo real.
- Filtro por categoría.
- Alta de productos mediante formulario, con validación de datos.
- Agregar productos al carrito con control de stock.
- Eliminar productos del carrito y reponer su stock.
- Cálculo de subtotal, IVA del 21% y total.
- Finalización de la compra con mensaje de confirmación.
- Mensajes visuales de éxito y error.
Tecnologías
- HTML5
- CSS3
- JavaScript: DOM, eventos y template strings
